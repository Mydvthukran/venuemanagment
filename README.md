# venuemanagment (VenueFlow)

VenueFlow is a **smart venue experience platform** prototype built with React + Vite.

## What it does
- Venue dashboard + operational insights
- Navigation suggestions based on congestion
- Queue insights + recommendations
- Food ordering module
- Scenario simulation mode

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
